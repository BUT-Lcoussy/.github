# 🎓 BUT Informatique - Projects Archive - Leandre Coussy

Welcome to this GitHub organization! This space serves as an archive and portfolio for the most important projects I developed during my 3 years studying for a **BUT Informatique** (Bachelor University of Technology in Computer Science).

## ⚠️ Repository Context & Missing Data

All the repositories hosted in this organization were originally developed and hosted on my university's private GitLab instance. To make them publicly accessible and showcase my work, I imported them here using a Git mirror.

Because these projects were migrated via command line (using `git push --mirror`), **only the core Git versioning data has been transferred**. 

### ✅ What is preserved:
* The source code
* The complete commit history
* All branches (e.g., `main`, `dev`, and various feature branches)
* Git tags (e.g., `1.0`, `0.5-alpha`)

### ❌ What is missing:
GitLab-specific metadata does not transfer over a standard Git push. Therefore, you will not find:
* Issues and bug tracking history
* Project boards (Kanban/Agile boards)
* Merge Requests (MRs) / Pull Requests (PRs) discussions and reviews
* CI/CD pipelines and wiki pages
